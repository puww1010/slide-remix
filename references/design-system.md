# 扁平视觉规范（HTML 产物的默认风格）

来源：一张企业安全产品的"AI Agent 身份安全 + 本地 AI 网关"架构页（扁平、白底、颜色表示含义）。重绘图的字体颜色、背景、图示和图标都按它来。

## 画布与字体
- 16:9，1280×720 px，白底。HTML 外层是浅灰背景，画布是带细边框的白卡片。
- 字体：`-apple-system, "Helvetica Neue", Helvetica, Arial, "PingFang SC", "Noto Sans CJK SC", "Microsoft YaHei"`。
- 字号（px）：标题 24 粗；副标题 13；节点标题 13–13.5 粗；节点副标题和英文 10.5；分区标签 10.5 粗；连线标签 10–10.5 粗；卡片标题 13.5–14 粗；卡片正文 11.5–12；脚注 11。

## 颜色（语义固定，不随意换）
| 语义 | role | HTML 色值 | 用在哪 |
|---|---|---|---|
| 执法 / 安全 / 请求入口 | orange | #E8542F | 标题竖条、网关 / 安全节点、主请求线、编号徽章、结论横幅 |
| 调用 / 数据路径 | blue | #4263EB | 工具 / 模型调用线、外部系统节点、回流环 |
| 身份 / 上下文 / 记忆 | purple | #7C5CE0 | SSO、身份链路、上下文和记忆的读写 |
| 通过 / 状态 | green | #2E9E4F | 状态胶囊、勾选圆、编号圆、卡片顶条 |
| 次要阶段 | teal | #0F8B8D | 第 5 类分组 |
| 中性 | ink #1F2937 / muted #4B5563 / soft #6B7280 / line #E5E7EB / zone #F3F4F6 | | 文字、边框、分区底色 |

浅色底统一用 `C(role,'fill')`（约 7%）；分区边框用 `C(role,'border')`；重点节点（中枢、编排器、LLM）用 `C('green','dark')` 加 2–2.2px 描边。

## 组件
- **标题区**：左侧 5×48 橙色竖条，标题 24px 粗，副标题灰色 13px（y≈84）；右上角是绿色状态胶囊（240×44，圆角 22，带勾选圆，两行字），用来放一句核心结论。原图没有这句话时属于补充文字，必须报告。
- **分区**：大圆角框（rx 10），左上角放 10.5px 粗体标签。"自己运行 / 本地 / 执行区"用橙色虚线框加橙色 7% 底，其余分区用实线浅色框。
- **节点**：白底，1.4–1.7px 彩色描边，rx 7–8；标题和英文副标题居中；编号圆（r 8–9）放在左上角，离边 13px 左右。
- **连线**：2px，三角箭头；交叉处加跳线弧；标签用 `LABEL()`（白底），不要让箭头穿过文字。
- **编号联动**：图中的 ①②③ 对应底部卡片右上角的橙色编号徽章。
- **底部卡片**：白底细边，4px 绿色顶条，勾选圆 + 标题 + 两行说明，有编号联动时在右上角放橙色编号。
- **结论横幅**（可选）：橙色 7% 底，左侧 5px 橙色竖条，15px 粗体居中，关键句用橙色。
- **脚注**：灰色 11px，内容是图例、证据和限制条件。图例颜色词一律用 `cw()`。
- **图标**：极简，只给主体配，颜色用 gray 或 blue。
